# 코드와 문제은행의 이용 조건

## 코드와 자체 작성 내용

이 저장소의 프로젝트 자체 작성 앱 코드·도구·가이드 문서는 루트 `LICENSE`의 MIT 조건으로 제공합니다. 프로젝트 자체 작성 문항의 독창적 부분도 같은 허락 범위에 포함합니다. 기존 제3자 고지·외부 원천과 그 파생물의 조건을 없애거나 대체하는 허락은 아닙니다.

## 문제은행은 복합 라이선스

`app/content/`, `app/review/`의 외부 사전 자료·뜻풀이·파생 문항은 문항별 `sourceMetadata` 및 `metadata`의 원천·이용 조건을 따릅니다. 저장소 또는 npm package의 MIT 표지만 보고 문제은행 전체를 MIT라고 표시하지 마세요.

| 자료 | 유지할 조건과 고지 |
| --- | --- |
| 국립국어원 한국어기초사전 자료 및 해당 파생 텍스트 | CC BY-SA 2.0 KR, 원 출처·변경 표시·동일조건 유지 |
| Princeton WordNet 3.0 자료 | `WordNet-3.0.txt`의 저작권·허락·면책 전문 |
| 그 밖의 문항 | 개별 원천 및 작성 기록을 확인하고 필요한 고지를 유지 |

`PROJECT_OWNED` 자체는 외부 원천의 권리가 사라졌다는 증명이 아닙니다. 문항에 별도 원천·파생 조건이 있으면 그 조건을 함께 따릅니다. 이미지·음성·외부 예문 등 원천의 멀티미디어는 이 저장소에 포함하지 않습니다.

- 한국어기초사전 정책: https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo
- CC BY-SA 2.0 KR: https://creativecommons.org/licenses/by-sa/2.0/kr/
- WordNet 정책: https://wordnet.princeton.edu/license-and-commercial-use
- MIT 설명: https://choosealicense.com/licenses/mit/

추출 도구는 원래 문항 전체와 고지 파일을 함께 내보냅니다. 다른 앱에서 재배포할 때도 이 고지와 문항별 출처를 전달하세요. 콘텐츠 검토는 AI 수행 범위이며 사람 승인·법률 인증·학습 효과 검증을 뜻하지 않습니다.
