# 실행과 검증

```sh
npm test
npm run privacy:check
npm run build
```

이 공개본은 외부 npm 의존성 없이 Node 표준 모듈로 동작합니다. CI는 Ubuntu와 Node 22 두 버전에서 `npm run check`를 실행합니다.

자동 검사는 정적 문항 수·중복 ID·원래 데이터 해시·AI exact binding·전체 필드 보존 추출·변조 거부·개인정보 패턴·반복 빌드의 동일성·service worker 대상 파일을 확인합니다. 수학은 독립적인 산술 검증도 실행합니다.

브라우저 확인은 별도입니다. `node scripts/serve.mjs --dist`로 빌드 결과를 열고 가상 학습자만 사용합니다. 제출 뒤 답안 잠금, 보호자 수동 채점, 오답 재풀이와 저장 후 새로고침 복원을 확인합니다. 오프라인 준비 표시가 전체 오프라인 학습 시험을 대신하지 않습니다.

AI 검토·기술 시험을 사람 콘텐츠 승인이나 학습 효과 측정으로 표현하지 않습니다. 장치별 필기·손바닥 오입력·접근성은 실제 기기에서 별도로 확인해야 합니다.
